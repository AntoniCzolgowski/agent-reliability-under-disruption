# Agent reliability under disruption

Course project for CSCI 5612 by Antoni Czolgowski, with a research extension.

- `site/` holds the website (Astro, static). It is deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.
- `code/` holds the data preparation script.
- `notebooks/` holds the first-look notebook.

No raw or processed data is stored in this repository. The DataPrep_EDA tab of the site links to the original sources.

## Run the site locally

```
cd site
npm install
npm run dev
```
